# VB.NET Payroll Management System

## Overview

This project is a payroll management application developed using VB.NET Windows Forms. The application allows users to manage employee payroll information and calculate employee compensation through a user-friendly desktop interface.

## Features

- Employee payroll calculations
- Hourly employee management
- Salaried employee management
- Input validation
- User-friendly Windows Forms interface
- Object-oriented programming design

## Technologies Used

- VB.NET
- Windows Forms
- Visual Studio

## Skills Demonstrated

- Object-Oriented Programming (OOP)
- Software Development
- Desktop Application Development
- User Interface Design
- Data Validation
